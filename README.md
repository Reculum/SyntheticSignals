# Procedural Signal Generator (`signal_class`)

A lightweight, mathematically grounded Python module for **procedurally generating synthetic 1D discrete signals** with customizable non-stationary behavior, smooth curves, oscillatory patterns, step-function ("cartoon") discontinuities, and Generalized Gaussian noise.

Whether you are testing signal processing algorithms, training machine learning models, or benchmarking filtering and denoising techniques, `signal_class` provides a robust API to construct realistic composite signals with exact, extractable ground-truth components.

---

## 📐 Mathematical Framework & Signal Model

Given a signal length $n \in \mathbb{N}$, a **discrete signal** is represented as a vector $x \in \mathbb{R}^n$ with zero-based indices $x[j]$ for $j \in \{0, \dots, n - 1\}$.

### 1. Normalization Function
To maintain bounded signals, we define the normalization operator $Z: \mathbb{R}^n \to \mathbb{R}^n$:
$$Z(v) = \frac{v - v[0]}{\|v - v[0]\|_{\infty}}$$
A signal $x$ is defined as **normalized** if $Z(x) = x$.

### 2. Composite Signal Model
The generator constructs a normalized composite signal $f \in \mathbb{R}^n$ according to the model:
$$f = Z\left(\beta_s \cdot s + \beta_o \cdot o + \beta_c \cdot c + n\right)$$

Where:
* **$s \in \mathbb{R}^n$ (Smooth Component):** Continuous signal bounded by discrete curvature $K$.
* **$o \in \mathbb{R}^n$ (Oscillatory Component):** Waveform created via monotone interpolation functions between extrema.
* **$c \in \mathbb{R}^n$ (Cartoon Component):** Piecewise-constant signal with step discontinuities.
* **$\beta_s, \beta_o, \beta_c \in \mathbb{R}^+$ (Blending Factors):** Random scalar multipliers satisfying $\beta_s + \beta_o + \beta_c = 1$.
* **$n \in \mathbb{R}^n$ (Noise Component):** Independent and identically distributed (i.i.d.) random variables drawn from a Generalized Gaussian Distribution (GGD) with mean $\mu = 0$, shape parameter $\beta$, and scale derived from the Signal-to-Noise Ratio (SNR).

## 🧮 Discrete Curvature Formulation

For continuous functions $f \in C^2(\mathbb{R})$, curvature is given by:
$$K_f(x) = \frac{f''(x)}{[1 + f'(x)^2]^{3/2}}$$

In the discrete domain, `signal_class` discretizes curvature at index $j$ using three consecutive points $P_- = (j-1, s[j-1])$, $P = (j, s[j])$, and $P_+ = (j+1, s[j+1])$:
$$K_s[j] = 2 \cdot \tan\left(\frac{\theta}{2}\right)$$

where $|\theta| \in [0, \pi/2]$ represents the angle between the segment $\overline{PP_+}$ and the line extending through $P_-$ and $P$. A discrete signal is defined as **smooth** if:
$$\|K_s\|_{\infty} \le \frac{2}{n}$$

## ✨ Component Generation Details

### 1. Smooth Signal ($s$)
* Bounded by curvature constraints $\frac{1}{(n/4)^2 + 1} \le K \le \frac{2}{n}$.
* Generated by seeding a extremum index $i_0$, setting $s[i_0] = \pm 1$, and iteratively propagating values outward such that consecutive triplets satisfy $K_s[j] \le K$.
* Uses convex combinations of smooth prototype signals to guarantee $s[0] = 0$ and $\|s\|_{\infty} = 1$.

### 2. Oscillatory Signal ($o$)
* Utilizes a monotone interpolating function $I_f: [P_x, Q_x] \to [P_y, Q_y]$:
  $$I_f(x) = Q_y \cdot f\left(\frac{x - P_x}{Q_x - P_x}\right) + P_y \cdot \left[1 - f\left(\frac{x - P_x}{Q_x - P_x}\right)\right]$$
* Alternates extrema between $+1$ and $-1$ across randomly sampled index intervals of minimum length $T_{\min}$.
* Supports Cosine (`cos`), Linear (`lin`), and Heaviside Step (`step`) interpolation kernels.
* Optionally modulated by a smooth signal envelope.

### 3. Cartoon Signal ($c$)
* Piecewise-constant signal constructed over $n_{\text{jumps}}$ partitions.
* Determines the required number of jumps using uniform distribution binning probability thresholds $p \ge 0.95$:

  $$n_{\text{jumps}} = \min \left\lbrace j \in \mathbb{N} \;\Big|\; 1 - k \left( \frac{k-1}{k} \right)^j \ge p \right\rbrace$$

### 4. Generalized Gaussian Noise ($n$)
* Generates zero-mean noise with shape parameter $\beta > 0$.
* Standard deviation $\sigma$ is computed dynamically from the target Signal-to-Noise Ratio (SNR in dB):
  $$\sigma = 10^{-\frac{\text{SNR}}{20}} \cdot \frac{\|S\|_2}{\sqrt{n}}$$
  where $S = \beta_s s + \beta_o o + \beta_c c$.

## 🚀 Quick Start & Usage

### Basic Usage & Operator Overloading
`signal` instances support standard arithmetic operations (`+`, `-`, `*`):

```python
from signal_class import signal

# Initialize a signal of length 500
sig1 = signal(500)
sig2 = signal(500)

# Generate individual components
sig1.generate_smooth_sign(K=0.005)
sig2.generate_oscillatory_sign(
    interpolating_function=lambda x: (-np.cos(x * np.pi) + 1) / 2,
    n_ext=10,
    K=0.005
)

# Combine signals using arithmetic operators
composite_signal = sig1 + (0.5 * sig2)

# Extract raw numpy array
data_array = composite_signal.get_image()
```

### Generating a Full Blended Signal
The `generate_blended_signal` method creates a fully composite signal and returns all underlying ground-truth components as a tuple `(s, o, c, n)`:

```python
import matplotlib.pyplot as plt
from signal_class import signal

N = 1000  # Number of samples
sig = signal(N)

# Generate blended signal and extract ground-truth components
smooth, osc, cartoon, noise = sig.generate_blended_signal(
    snr_tuple=(10.0, 20.0),       # SNR range in dB
    beta_tuple=(0.5, 2.0),        # Shape parameter beta range for GGD noise
    T_min_cartoon=30,             # Minimum interval length for cartoon jumps
    prob_std_sin=0.2,             # Probability of unmodulated sinusoid oscillation
    kernel='cos'                  # Interpolation kernel ('cos', 'lin', or step)
)

# Plot the composite signal and its components
plt.figure(figsize=(12, 10))

plt.subplot(5, 1, 1)
plt.plot(sig.get_image(), color='black', linewidth=1.2)
plt.title("Observed Blended Signal f")
plt.grid(True)

plt.subplot(5, 1, 2)
plt.plot(smooth.get_image(), color='blue')
plt.title("Smooth Component (s)")
plt.grid(True)

plt.subplot(5, 1, 3)
plt.plot(osc.get_image(), color='green')
plt.title("Oscillatory Component (o)")
plt.grid(True)

plt.subplot(5, 1, 4)
plt.plot(cartoon.get_image(), color='orange')
plt.title("Cartoon Component (c)")
plt.grid(True)

plt.subplot(5, 1, 5)
plt.plot(noise.get_image(), color='red', alpha=0.7)
plt.title("Generalized Gaussian Noise Component (n)")
plt.grid(True)

plt.tight_layout()
plt.show()
```

## 📚 API Reference

### Attributes & Basic Operations
* `signal(n)`: Constructor for a signal of length `n`.
* `len(sig)`: Returns length $n$.
* `sig[j]`: Index access for element at position $j$.
* `sig1 + sig2`: Component-wise addition of two signals.
* `lambda * sig`: Scalar multiplication.
* `get_image()`: Returns a copy of the internal NumPy array.

### Generation Methods
* `generate_smooth_sign(K, must_be_normalized=True)`: Generates a smooth signal profile bounded by curvature $K$.
* `generate_oscillatory_sign(interpolating_function, n_ext, K, T_min=10, std_sin=False)`: Creates an oscillatory signal using custom interpolation kernels.
* `generate_cartoon_sign(n_partitions, T_min, p=0.95)`: Generates a piecewise-constant step signal.
* `generate_GG_realization(media, std_dev, beta)`: Generates i.i.d. noise following a Generalized Gaussian PDF.
* `generate_blended_signal(snr_tuple, beta_tuple, T_min_cartoon, prob_std_sin, kernel='cos')`: Constructs a full composite signal and returns `(smooth, osc, cartoon, noise)`.
* `return_curvature_vect()`: Returns a NumPy array containing the discrete curvature at each internal index.
